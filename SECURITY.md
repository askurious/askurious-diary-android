# Security

## Reporting a vulnerability

Please report security issues privately through GitHub's "Report a vulnerability" button on the Security tab of this
repository (private vulnerability reporting), not in public issues or pull requests. If you cannot use GitHub, write
to Philipp Brauner (brauner@comm.rwth-aachen.de) or Ralf Philipsen (philipsen@comm.rwth-aachen.de). Describe what you
found, how to reproduce it, and which version of the app (its "About" screen) or which commit you looked at.

We confirm receipt within a few working days, keep you informed, and name you in the release notes if you wish.
Please give us reasonable time to fix the issue before you make it public.

## Scope

This repository holds the Android app for diary studies of Askurious. The server side is in
[askurious/askurious](https://github.com/askurious/askurious), with its own security policy. For a problem with a
particular installation (for example askurious.de), use the contact in that installation's legal notice
("Impressum").

## Supported versions

Only the current state of the main branch and the newest published version of the app receive security fixes.
